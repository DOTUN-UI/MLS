# Matchday Workforce Careers

A stadium hiring hub modeled on the **careers-site flow** of [jobs.mlssoccer.com](https://jobs.mlssoccer.com) — storytelling first, then job search — while remaining an independent Matchday Workforce brand (not an MLS clone).

Built with **HTML, CSS, and JavaScript**.

## Careers flow (like MLS Careers)

1. **Home** — full-bleed hero (“We're fueled by matchday”) + **Search jobs**
2. **Who We Are** — mission / crew story
3. **We are…** — hosts, operators, creators
4. **Values** — horizontal scroll (hospitality, teamwork, safety, …)
5. **Jobs** — searchable openings → apply

### Nav

Home · Departments · Work Life · Community · About · **Jobs** (red)
